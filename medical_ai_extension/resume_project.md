# 简历项目描述：面向医疗 AI 应用的接口自动化测试框架设计与实践

## 项目描述

基于 Python + Pytest 的通用接口自动化测试框架进行学习与二次改造，结合本人智慧医疗与疾病预测模型相关研究方向，设计面向医疗 AI 应用的接口自动化测试方案。框架采用分层架构，支持多环境配置、YAML 数据驱动、统一接口请求封装、测试报告生成及 Jenkins CI/CD 集成，主要用于模拟疾病预测 API、医疗数据处理接口及模型服务迭代后的自动化回归测试场景。

## 主要工作

- 学习并梳理原始框架的分层架构，明确配置层、数据层、工具层、用例层和报告层职责，实现测试用例、测试数据与执行逻辑解耦。
- 基于 YAML 设计数据驱动测试用例，围绕疾病预测 API 构造正常输入、缺失字段、异常参数、边界值等测试场景，提高接口测试覆盖度。
- 针对医疗 AI 模型接口输出特点，设计状态码、返回字段完整性、预测概率范围、风险等级枚举值、模型版本号等多维度断言规则。
- 结合医疗多源数据特点，设计 MySQL、MongoDB、Redis、ClickHouse 在测试数据准备、接口结果校验和测试后数据清理中的应用方案。
- 学习 Jenkins CI/CD 自动化测试流程，实现测试任务执行、测试报告生成与结果归档，为模型服务或接口变更后的回归测试提供支撑。

## 个人收获

通过该项目，掌握了接口自动化测试框架的分层设计思想，熟悉了 Python、Pytest、YAML 数据驱动、Requests 请求封装和 Jenkins 持续集成流程；同时结合医疗 AI 场景，理解了模型服务接口测试中对输入数据质量、输出结果稳定性、模型版本可追溯性和自动化回归验证的要求。

## 面试说明建议

该项目不是完全从零开发的真实医院生产项目，而是在通用接口自动化测试框架基础上进行的学习、理解和医疗 AI 场景化改造。面试时建议重点说明：

1. 原框架提供通用接口测试能力；
2. 个人主要完成医疗 AI 场景设计、测试用例设计和断言规则扩展；
3. 多数据源部分属于方案设计和可扩展方向；
4. 后续可继续补充 FastAPI 模拟疾病预测服务、真实数据库连接和模型指标回归测试。
